# Programmable USB Drive

*by muru.global*

## Title
Programmable USB Drive — One-Touch Typer for Passwords, Links and Text (Set It Up in Your Browser)

## Short description
A tiny USB stick that types a saved piece of text for you at the press of a button. Put
in a strong password, a Wi-Fi code, a link, or any text you type often. Set it up in
your web browser in a minute. No app to install, no cloud account.

## Long description
This is the small helper for anything you type again and again. You store one piece of
text on the stick, and from then on a single button press types it out on any computer,
exactly as if you had typed it yourself.

Use it for:

- A long, strong **password** you never want to type by hand.
- Your guest **Wi-Fi code** for visitors.
- A **link** to your profile, portfolio, menu, or booking page.
- A block of **boilerplate text**, an address, or a support reply you send all the time.

Setup is done in your web browser, not with any technical tool. Plug the stick in, open
the setup page, and choose how to load your text. You can type it in yourself, have the
browser generate a strong random password for you, or have the stick generate one on
its own so it is never shown on screen. To save it, you press the button on the stick to
confirm. That physical press means no website or program can change what is stored
without you.

Privacy is built in. The stick never gives the stored text back to a computer. There is
no read-back. When you want to change it, you wipe it and set a new one. The old text is
erased and cannot be recovered. What is on the stick stays on the stick.

Highlights:

- **One button, your text.** Press once, it types.
- **Set up in the browser.** Works in Chrome and Edge. Nothing to install.
- **Three ways to load it.** Type your own, generate in the browser, or generate on the
  device so it is never seen.
- **You are in control.** Every change needs a button press on the stick.
- **Nothing leaks.** No read-back, and wipe erases for good.
- **No drivers, no battery.** Plug in and go on Windows, macOS and Linux.

Please note: this is a programmable typing device, not a file storage drive. It stores
one text entry, not documents or photos. It types using the US keyboard layout, so on a
very different layout some symbols may come out differently, the same as any USB
keyboard. Setup needs Chrome or Edge on a computer or Android. Safari and iPhone are not
supported for setup.

## Technical specifications

| Item | Detail |
|---|---|
| Function | Types one stored text entry on button press |
| Stored entry | Up to 60 characters, letters, numbers and symbols |
| Setup | In-browser over USB (WebHID), Chrome or Edge |
| Generation | In browser, or on the device using its hardware random generator |
| Privacy | No read-back to the host. Wipe erases the entry permanently |
| Confirm action | Physical button press for every save or wipe |
| Controller | STM32L442, Arm Cortex-M4, 80 MHz |
| Connector | USB-A, built into the board edge (no cable) |
| Speed | USB 2.0 Full-Speed |
| Indicator | Status LED |
| Power | From USB. No battery |
| Types on | Windows, macOS, Linux (US keyboard layout) |
| Set up on | Chrome or Edge (desktop), Chrome on Android |
| Size | About 48 x 21 mm |

*Rev V1A. Specifications may change.*
